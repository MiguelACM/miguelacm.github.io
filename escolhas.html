1. Academic Assignment Criteria & Custom Inspector

The M1 evaluation mandates strict data constraints to guarantee statistical validity for subsequent supervised/unsupervised tasks (M2). Use the interactive tool below to test whether any prospective dataset fulfills all academic requirements.

Mandatory Parameters M1 Specification

  • 1. Real-World Origin: Synthetic datasets are strictly prohibited. Data must be sourced from repositories like UCI or OpenML.
  • 2. Binary Target: Target feature must represent a two-class decision outcome (0 or 1).
  • 3. Mixed Data Types: Must contain at least one attribute of each type: Numerical (continuous/discrete), Nominal (unranked categorical), and Ordinal (ranked categorical).
  • 4. Dimensionality: $8 \le \text{Predictor Features} \le 30$. Total sample size $N \ge 1000$.
Warning on Ordinal Data: Continuous numerical variables (like age) are NOT ordinal. Ordinal attributes must represent discrete ordered levels (e.g., education tiers or payment delay codes).
